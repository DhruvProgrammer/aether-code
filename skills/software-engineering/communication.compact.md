# Communication (compact)

- Report as: Confirmed (verified) / Assumed (chosen, unstated) / Unknown (unestablished) / Blocked (prevents progress) / Completed (acceptance + validation passed).
- Never claim tests passed unrun, bugs fixed unverified, APIs working unchecked, docs updated untouched.
- Completion report: completed tasks, validation results, files changed, assumptions, limitations, docs updated. Final review: requirements addressed, simplicity, surgical diff, correctness, safety, docs, diff reviewed.
